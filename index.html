👯‍♂️ Motor de Registros Únicos

ℹ️ ¿Qué hace esta función? Escanea todo tu Excel buscando valores repetidos en la columna que indiques. Conserva un solo registro único y elimina los duplicados. Ideal para limpiar padrones, listas de clientes o consolidar inventarios.

🎯 Extracción Selectiva

ℹ️ ¿Qué hace esta función? Funciona como un colador avanzado. Lee una base de datos gigante y crea un nuevo archivo extrayendo *únicamente* las filas que coincidan exactamente con la palabra o valor que estás buscando.

🧹 Limpieza de Estructura

ℹ️ ¿Qué hace esta función? Te permite borrar múltiples columnas de un solo golpe. Perfecto cuando el sistema informático te exporta un archivo con 50 columnas y solo necesitas presentar 5 para tu reporte final.
Importa tu archivo abajo para ver las columnas...

📑 Separador de Hojas Inteligente

ℹ️ ¿Qué hace esta función? Toma tu archivo principal y lo divide automáticamente creando múltiples pestañas (hojas) dentro del mismo Excel, una por cada categoría distinta que encuentre en la columna indicada.

📊 Generador de Resumen (Conteo)

ℹ️ ¿Qué hace esta función? Cuenta matemáticamente cuántas veces se repite cada elemento de una columna y te genera una tabla estadística ordenada de mayor a menor frecuencia. Excelente para métricas rápidas.

🔎 Auditoría de Datos Vacíos

ℹ️ ¿Qué hace esta función? Es un detector de inconsistencias. Revisa toda tu base de datos y extrae *solo* aquellas filas que tengan la columna indicada completamente en blanco (sin datos).

📝 Formateador de Textos

ℹ️ ¿Qué hace esta función? Limpia errores de tipeo. Elimina espacios dobles accidentales y convierte todo el texto de la columna seleccionada a MAYÚSCULAS, minúsculas o Tipo Título para estandarizar bases de datos.

🎭 Anonimizador de Datos (Privacidad)

ℹ️ ¿Qué hace esta función? Enmascara datos sensibles (Data Masking). Reemplaza partes de correos, números telefónicos o identificaciones con asteriscos (***) para que puedas compartir reportes sin violar la privacidad.

🎲 Extracción de Muestra Aleatoria

ℹ️ ¿Qué hace esta función? Aplica un algoritmo matemático (Fisher-Yates) para elegir filas completamente al azar de tu archivo. Indispensable para realizar auditorías imparciales, encuestas o controles de calidad.

🧩 Consolidador Multimodal

ℹ️ ¿Qué hace esta función? Une múltiples archivos de Excel en uno solo. Apila las filas de todos los documentos que subas uno debajo del otro de manera inteligente, generando una única Base Maestra.
